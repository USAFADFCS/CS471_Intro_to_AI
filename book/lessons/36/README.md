## L36 Failure Modes and Ethics
**Objectives:** Identify hallucinations and bias; explain the necessity of Explainable AI (XAI) for mission-critical systems; evaluate deployment risks including data poisoning and adversarial evasion.

* Identify and document instances where an LLM hallucinates a non-existent protocol when asked about specific Rules of Engagement (ROE).
* Apply an Explainable AI (XAI) tool (such as SHAP) to interpret exactly which features caused a model to flag a specific sensor reading as a threat, ensuring human operators can trust the system.
* Draft a comprehensive deployment risk assessment for an autonomous drone wingman. Detail defenses against data poisoning (e.g., adversaries subtly modifying physical camouflage to evade CNNs) and alignment with DoD AI Ethical Principles.

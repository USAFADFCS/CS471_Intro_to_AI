## L34 Prompt Engineering
**Objectives:** Apply zero-shot, few-shot, and chain-of-thought prompting; optimize for token limits and latency constraints; identify and mitigate prompt injection vulnerabilities.

*   **Simple:** Apply zero-shot prompting to extract call signs, coordinates, and timestamps from unstructured intercepted text, optimizing the prompt length to reduce API latency for real-time processing.
*   **Moderate:** Design a few-shot prompting strategy to classify the intent and urgency of open-source intelligence (OSINT) gathered from social media.
*   **Complex:** Implement a chain-of-thought prompt that forces the LLM to explain its reasoning step-by-step when developing a tactical Course of Action (COA). Simulate a prompt injection attack (e.g., an adversary hiding malicious instructions in intercepted text) and design defensive system prompts.

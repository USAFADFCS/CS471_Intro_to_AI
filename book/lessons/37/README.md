## L37 Agentic AI
**Objectives:** Explain agentic reasoning loops (e.g., ReAct); design multi-step workflows with tool use and memory; evaluate system recovery from failed tool calls.

*   **Simple:** Map out a multi-step workflow for an AI agent tasked with parsing an intelligence alert, cross-referencing weather conditions, and drafting an alert for the squadron commander.
*   **Moderate:** Design a ReAct (Reasoning and Acting) loop agent that uses simulated tools (e.g., calling a "Weather API" and checking "Airspace Restrictions") to plan a supply airdrop. Test how the agent adjusts its plan when a tool returns an error.
*   **Complex:** Evaluate a multi-agent architecture simulating a wargame, where a "Red Team" agent proposes adversary maneuvers and a "Blue Team" agent counters them. Analyze the strengths and limitations of agent memory and planning over long simulated campaigns.

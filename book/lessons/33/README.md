## L33 Transformers and LLMs
**Objectives:** Explain tokenization, positional encoding, and self-attention; describe the pre-training and instruct-tuning paradigms; interact with LLMs using APIs.

*   **Simple:** Tokenize a complex Intelligence, Surveillance, and Reconnaissance (ISR) report to understand how LLMs break down military jargon. Observe how positional encodings tag the order of coordinate data.
*   **Moderate:** Interact with an LLM API to summarize lengthy After Action Reports (AARs). Analyze how transformer self-attention weights theoretically link entities (like unit names and locations) across long documents.
*   **Complex:** Compare the behavior of a foundational base model versus an instruct-tuned model when asked to generate a daily intelligence briefing from a raw feed of disparate global events.

**Mathematical Notation for Decision-Making**
* $\max(a, b)$: A function that returns the greatest value between options $a$ and $b$.
* $\min(a, b)$: A function that returns the lowest value between options $a$ and $b$.
* $E[X]$: The Expected Value of a stochastic variable $X$.
* $P(x)$: The exact probability of a specific event $x$ occurring (where probabilities sum to 1.0).

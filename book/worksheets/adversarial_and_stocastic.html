Game Rules & Agent Mechanics
  • Zero-Sum Objective: Rover (MAX) seeks to maximize utility; Drone (MIN) seeks to minimize it.
  • Turn Order: Rover moves first each round, followed immediately by Drone's counter-move.
  • Energy Cores (⚡): Stepping on a core claims it for +50 pts. The other agent is permanently denied those points.
  • Collision / Capture: If Drone intercepts Rover, the mission terminates immediately: MIN earns +100 pts, while MAX suffers a catastrophic -500 penalty.
  • Proximity Gradients: Continuous distance heuristics pull Rover toward cores ($+$ score) and Drone toward cores ($-$ score) to prevent horizon blindness when cores are beyond the search depth.
  • Agent Policies:
    • Minimax: MAX assumes MIN plays optimal counter-moves to deny cores and trap the Rover.
    • Expectimax: MAX models MIN as a stochastic agent taking random uniform actions, maximizing expected utility ($E[V]$).

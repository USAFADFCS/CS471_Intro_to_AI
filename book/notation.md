

# Notation Reference


## L1: Intro to Artificial Intelligence

### The Confusion Matrix 
While L1 is primarily conceptual, the evaluation of an agent's performance relies on the fundamental classification matrix:
| Notation | Definition |
| --- | --- |
| $TP$ | True Positive: The agent correctly predicted the presence of a target/condition. |
| $TN$ | True Negative: The agent correctly predicted the absence of a target/condition. |
| $FP$ | False Positive: The agent incorrectly predicted a target/condition (Type I Error / False Alarm / Collateral Risk). |
| $FN$ | False Negative: The agent incorrectly predicted the absence of a target/condition (Type II Error / Missed Threat). |

## L4: Problem Formulation
### Search Algorithm Properties
| Notation | Definition |
| --- | --- | 
| $b$ | Branching Factor: The average number of successor options available to an agent from any given node in a search tree. |
| $m$ | Maximum Depth: The maximum depth of the search tree (number of steps from the root to the deepest possible state). |
| $O(b^m)$ | Time Complexity: The Big-O mathematical representation of the total number of nodes in the entire search tree. |
| $O(bm)$ | Space Complexity (DFS): The memory required by Depth-First Search, as it only stores the current path (siblings up to the root) in its fringe. |

## L5: Uninformed Search
### Space and Time Complexity
| Notation | Definition |
| --- | --- | 
| $s$ | Shallowest Solution Depth: The depth level of the shallowest goal state in the search tree. Used in BFS calculations. |
| $C^*$ | Optimal Cost: The total mathematical cost of the absolutely cheapest path to the goal. Used in UCS calculations. |
| $\epsilon$ | Minimum Arc Cost: The smallest possible cost of making a single move/action in the environment. UCS relies on this being greater than 0. |
| $O(b^m)$ | Time Complexity (DFS): The Big-O mathematical representation of the total number of nodes in the entire search tree. |
| $O(bm)$ | Space Complexity (DFS): The memory required by Depth-First Search, as it only stores the current path (siblings up to the root) in its fringe. |
| O(b^s)$ | Time/Space Complexity (BFS): The Big-O metric for Breadth-First Search, which grows exponentially with the depth of the shallowest goal. |
| $O(b^{C^*/\epsilon})$ | Time/Space Complexity (UCS): The Big-O metric for Uniform Cost Search, derived from the branching factor exponentially raised to the "effective depth" of the cost contours. |

## L7: Heuristics
### Admissibility and Consistency

| Notation | Definition |
| --- | --- |
| $h(n)$ | The heuristic function. The estimated cost from the current node $n$ to the goal. |
| $h^*(n)$ | The true, exact cost from the current node $n$ to the goal. |
| $\text{cost}(A \to C)$ |  The exact step cost of traveling directly from node A to neighboring node C. |
| $\max(h_a, h_b)$ | A method of creating a superior heuristic by taking the maximum value of two admissible heuristics at every node. |

### Logistic Regression

| Notation | Definition |

### Linear Discriminant Analysis (LDA)

| Notation | Definition |
| --- | --- |
| $P(Y=k \mid X=x)$ | The posterior probability that the observation $X$ belongs to a specific class $k$, given the evidence $x$. |
| $f_k(x)$ | The probability density function for class $k$. Represents how likely you are to see feature values $x$ assuming the observation belongs to class $k$. |
| $\pi_k$ | The prior probability of class $k$. The baseline historical frequency of the class before seeing any new evidence. |
| $K$ | The total number of possible classes. |
| $\sum_{l=1}^{K}$ | The sum of the probabilities across all possible classes, used as the denominator to normalize the final output into a valid percentage. |

### Quadratic Discriminant Analysis (QDA)

| Notation | Definition |
| --- | --- |
| $\delta_k(x)$ | The discriminant score for class $k$. The model calculates this score for all classes and classifies the observation as the class with the highest score. |
| $\Sigma_k$ | The covariance matrix for class $k$. Unlike LDA, QDA allows each class to have its own variance/spread. |
| $\lvert \Sigma_k \rvert$ | The determinant of the covariance matrix. |
| $\Sigma_k^{-1}$ | The inverse of the covariance matrix. |
| $\mu_k$ | The mean (average) vector of the features for class $k$. |
| $x^T$ | The transpose of the feature vector $x$ (used for matrix multiplication). |
| $\sigma_k^2$ | The variance of class $k$ (used in the simplified 1D formula). |
| $\ln()$ | The natural logarithm. |

### Support Vector Machines (SVM)

| Notation | Definition |
| --- | --- |
| $w$ | The weight vector. This defines the orientation of the hyperplane separating the classes. |
| $\lVert w \rVert$ | The magnitude (or Euclidean norm) of the weight vector. |
| $b$ | The bias term, which defines the offset of the hyperplane from the origin. |
| $\min_{w,b}$ | The mathematical objective function. Instructs the algorithm to find values of $w$ and $b$ that minimize $\frac{1}{2} \lVert w \rVert^2$, maximizing the margin between classes. |

### The Bias-Variance Tradeoff

| Notation | Definition |
| --- | --- |
| $E[(y - \hat{f}(x))^2]$ | The expected Mean Squared Error of the model. |
| $y$ | The true, actual target value in the real world. |
| $\hat{f}(x)$ | The predicted value generated by the model based on input $x$. |
| $\text{Bias}(\hat{f}(x))^2$ | The squared bias. Represents error introduced by the model making overly simplistic assumptions (underfitting). |
| $\text{Var}(\hat{f}(x))$ | The variance. Represents error introduced by the model being overly sensitive to noise in the training data (overfitting). |
| $\sigma^2$ | The irreducible error. Represents the inherent randomness or "fog of war" in the system that no model can ever predict. |

### Decision Trees & Gini Impurity

| Notation | Definition |
| --- | --- |
| $Gini$ | The Gini Impurity score. A measure of how "mixed" a node is. A score of $0$ means the node is perfectly pure (contains only one class). |
| $C$ | The total number of different classes present in that specific node. |
| $p_i$ | The probability (or proportion) of an observation belonging to class $i$ within that specific node. |
| $\sum_{i=1}^{C}$ | The sum of the squared probabilities for all classes in the node. |

## L28: Naive Bayes Classification

### The Core Concept: Bayes' Theorem

| Notation | Definition |
| --- | --- |
| $P(\text{Class} \mid \text{Evidence})$ | **The Posterior:** The updated probability that a data point belongs to a specific Class, given the new Evidence just observed. |
| $P(\text{Evidence} \mid \text{Class})$ | **The Likelihood:** The probability of observing this specific Evidence, assuming the data point *does* belong to that Class. |
| $P(\text{Class})$ | **The Prior:** The baseline historical probability of the Class occurring, before any new evidence is considered. |
| $P(\text{Evidence})$ | **The Marginal Probability:** The total probability of observing this evidence across all possible classes. |

### Text Classification

| Notation | Definition |
| --- | --- |
| $w_1, w_2, \dots, w_n$ | A sequence of individual words in a text document or message (e.g., $w_1 =$ "Enemy", $w_2 =$ "spotted"). |
| $\propto$ | "Proportional to." Indicates a relative score rather than a true probability, as the marginal probability denominator is dropped. |
| $\prod_{i=1}^{n}$ | The mathematical product operator. Instructs the algorithm to multiply a sequence of terms together. |

### Zero-Frequency Events & Laplace Smoothing

| Notation | Definition |
| --- | --- |
| $P(w \mid C)$ | The smoothed likelihood probability of word $w$ occurring in Class $C$. |
| $\text{count}(w, C)$ | The raw number of times word $w$ historically appeared in Class $C$ during training. |
| $\alpha$ | The smoothing parameter. Usually set to $1$ (Add-One smoothing) to mathematically pretend we have seen every word at least once. |
| $\lvert V \rvert$ | The total size of the vocabulary. Represents the number of *unique* words the model knows about across all classes combined. |

## L30: Neural Networks II

| Notation | Definition |
| --- | --- |
| $L$ | **Loss (Cost):** The calculated error of the neural network's prediction. The network's entire goal is to minimize this number. |
| $\hat{y}$ | (Y-hat). The predicted output generated by the network. |
| $y$ | The true, actual target value the network was attempting to predict. |
| $\nabla L$ | The **Gradient**. A vector of partial derivatives representing the direction of steepest ascent for the Loss function. |
| $\frac{\partial L}{\partial w}$ | The partial derivative of the Loss with respect to a specific weight $w$. It tells the network how much that specific weight contributed to the total error. |
| $\alpha$ | **Learning Rate (Alpha):** A hyperparameter that controls the step size the network takes during weight updates. |
| $w_{new}$ | The updated weight after a single step of Gradient Descent. |

### Regularization

| Notation | Definition |
| --- | --- |

## L33: Transformers and LLMs Self-Attention Mechanism

| Notation | Definition |
| --- | --- |
| $Q$ | Query: A vector representation of the current token (word) the model is analyzing. It essentially asks, "What related information am I looking for?" |
| $K$ | Key: A vector representation assigned to every other word in the sequence. It serves as a label or identifier describing what information that word contains. |
| $V$ | Value: The actual meaning or semantic content of the word associated with a specific Key. |
| $QK^T$ | The dot product of the Queries and Keys. This mathematical operation calculates the raw relevancy score between the current word and every other word in the document. |
| $d_k$ | The dimensionality (size) of the Key vectors. Used in the formula $\frac{QK^T}{\sqrt{d_k}}$ as a scaling factor to keep the attention scores mathematically stable before they are passed to the softmax function. |
| $\text{softmax}$ | A mathematical function that converts the raw attention scores into a clean probability distribution (where all weights sum to exactly 1.0), determining exactly what percentage of attention the model should pay to each word. |


## L35: Retrieval-Augmented Generation

| Notation | Definition |
| --- | --- |
| $\vec{A}, \vec{B}$ (or $\mathbf{E}$) | Continuous, high-dimensional vector arrays representing the mathematical embedding of specific chunks of text. |
| $\vec{A} \cdot \vec{B}$ | The Dot Product: The sum of the products of the corresponding entries of two sequences of numbers. In vector math, this measures how closely two vectors align directionally. |
| $\Vert{}\vec{A}\Vert{}$ | The Magnitude: The physical "length" (or L2 Norm) of the vector, calculated using the Pythagorean theorem extended to higher dimensions. |
| $\cos(\theta)$ | Cosine Similarity: The core metric used in semantic search to compare two vectors ($\vec{A}$ and $\vec{B}$). Calculated as $\frac{\vec{A} \cdot \vec{B}}{\Vert{}\vec{A}\Vert{} \Vert{}\vec{B}\Vert{}}$. A score of $1$ means identical direction; $0$ means orthogonal (unrelated). |
| $C_s$ | Chunk Size: The mathematical constraint defining the maximum number of tokens allowed in a single segmented document block. |
| $C_o$ | Chunk Overlap: The number of tokens repeated from the end of the previous chunk into the beginning of the current chunk, used to preserve context across splits. |


## L36: Failure Modes and Ethics

Explainable AI (SHAP) 
| Notation | Definition |
| $\text{Prediction}$ | The final, raw output generated by the machine learning model (e.g., an engine wear score of 75). |
| $\text{Baseline}$ | (Or Expected Value). The average prediction of the model across the entire training dataset, acting as the starting point before any specific features are considered. |
| $\phi_i$ | The SHAP value for feature $i$. The specific numerical contribution (positive or negative) that feature $i$ made in pushing the prediction away from the baseline. |
| $\sum_{i=1}^{M} \phi_i$ | The sum of all individual SHAP values for a specific observation. Mathematically, the Baseline + this Sum must always equal the final Prediction. |

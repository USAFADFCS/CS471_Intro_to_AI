1. You are analyzing an AI routing algorithm for a mechanized unit using the State Space Graph above. The AI's onboard heuristic calculates $h(\text{Alpha}) = 45$.

Calculate the true cost to the goal ($h^*$) from Waypoint Alpha. Is this heuristic admissible? What is the operational risk of deploying $A^*$ with this heuristic?

<details>
  <summary>Show solution</summary>

**Step 1:** Define the mathematical rule for admissibility.
Admissibility requires that $0 \le h(n) \le h^*(n)$. The heuristic must never overestimate the true cost.

**Step 2:** Calculate the true cost ($h^*$) from Waypoint Alpha to the Goal.
* $15 \text{ (to Bravo)} + 25 \text{ (to Goal)} = 40$.
* $h^*(\text{Alpha}) = 40$.

**Step 3:** Compare the values.
* $h(n) = 45$. 
* $h^*(n) = 40$.
* Because $45 > 40$, the heuristic overestimates the cost.

**Answer:**

No, the heuristic is not admissible. By overestimating the true cost of Waypoint Alpha, the $A^*$ algorithm will artificially inflate the $f(n)$ score of this path. The operational risk is that the AI will abandon this potentially optimal route and select a more expensive, suboptimal path, violating the mathematical guarantee of Optimality.

</details>

2. An autonomous submarine is navigating underwater trenches based on the graph above.
Is the heuristic consistent between Trench A and Trench B? Furthermore, is the heuristic admissible at Trench A?

<details>
  <summary>Show solution</summary>

**Step 1:** Define the mathematical rule for consistency (the triangle inequality).

* $h(A) \le \text{cost}(A \to B) + h(B)$

Step 2: Insert the scenario values into the consistency formula.

* $20 \le 5 + 12$

* $20 \le 17$ (This is False).

Step 3: Check for admissibility at Trench A.

* True cost $h^*(A) = 5 + 15 = 20$.

* Heuristic $h(A) = 20$.

* $20 \le 20$ (This is True, so it is perfectly admissible).

**Answer:**
No, the heuristic is inconsistent. The mathematical statement $20 \le 17$ is false. The heuristic estimate "shrank" by 8 minutes, even though the submarine only traveled for 5 minutes. Even though the heuristic is mathematically admissible (it does not overestimate the true total cost of 20), its inconsistent nature violates monotonicity and makes it unsafe for Graph Search.


</details>

3. You have a drone flying over the environment shown above. You are testing two different admissible heuristics:

**Heuristic 1** ($h_1$): $h_1(A) = 2$, $h_1(B) = 5$

**Heuristic 2** ($h_2$): $h_2(A) = 3$, $h_2(B) = 4$

Neither heuristic strictly dominates the other (because $h_1$ is better at B, but $h_2$ is better at A). Using the heuristic semi-lattice rule, create a new, superior Heuristic 3 ($h_3$). What are the values for $h_3$, and does it dominate both $h_1$ and $h_2$?


<details>
  <summary>Show solution</summary>


**Step 1:** Define the rule for combining heuristics.
To create a superior admissible heuristic from two existing admissible heuristics, you take the maximum value at every node: $h_3(n) = \max(h_1(n), h_2(n))$.

**Step 2:** Calculate $h_3$ for Node A and Node B.

* $h_3(A) = \max(2, 3) = 3$

* $h_3(B) = \max(5, 4) = 5$

**Step 3:** Define dominance and evaluate. $h_3$ dominates $h_1$ if $h_3(n) \ge h_1(n)$ for all nodes.

* **At A:** $3 \ge 2$ (True), $3 \ge 3$ (True)

* **At B:** $5 \ge 5$ (True), $5 \ge 4$ (True)

**Answer:**
The values for the combined heuristic are $h_3(A) = 3$ and $h_3(B) = 5$.
Yes, $h_3$ strictly dominates both $h_1$ and $h_2$. Because it takes the maximum safe value at every single node, it provides an estimate that is closer to the true cost without ever overestimating it. Deploying $A^*$ with $h_3$ will mathematically guarantee the optimal path while exploring fewer nodes than either $h_1$ or $h_2$ individually.


</details>

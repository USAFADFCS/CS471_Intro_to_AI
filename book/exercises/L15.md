## Active vs. Passive Reinforcement Learning

**Scenario:** An underwater autonomous sentry is deployed to patrol a naval choke point. 

<details>
  <summary>Show solution</summary>

  **Step 1:** Identify if the agent determines its policy based on a probability distribution or while experimenting. Passive reinforcement learning entails conducting several experiments to evaluate a fixed policy.

  **Step 2:** Active reinforcement learning updates the world model or Q-values while actively experimenting and choosing actions.

  **Answer:**
  If the sentry acts purely on a pre-loaded patrol route to learn its value, it is passive. If it alters its route dynamically based on sonar feedback to maximize interception rewards, it is using active reinforcement learning.

</details>

## Q-Value Updates

**Scenario:** A missile defense tracking system (State S) tracks a target and takes the action to "Lock On" (Action A). The immediate reward is $+50$. The system transitions to a new state (State S') where the maximum future Q-value is $100$. Assume a discount factor ($\gamma$) of $1$ and a learning rate ($\alpha$) of $0.5$. The old $Q(S,A)$ estimate was $20$.

<details>
  <summary>Show solution</summary>

  **Step 1:** Calculate the sample estimate using the formula: $sample = R(s,a,s') + \gamma \max_{a'} Q(s',a')$. 
  $sample = 50 + (1 \times 100) = 150$.

  **Step 2:** Incorporate the new estimate into the running average using the Q-learning update formula: $Q(s,a) \leftarrow (1 - \alpha)Q(s,a) + (\alpha)[sample]$.
  $Q(s,a) = (0.5 \times 20) + (0.5 \times 150) = 10 + 75$.

  **Answer:**
  The new Q-value for locking onto the target is 85.

</details>

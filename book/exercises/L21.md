**Inference by Enumeration (Causal Inference)**
An autonomous air-defense system operates with three binary variables:

$A$: Adversary Airborne Jammer Active ($1$) vs. Inactive ($0$). Prior: $P(A=1) = 0.20$.

$R$: Radar Tracking Noise High ($1$) vs. Low ($0$).

$P(R=1 \mid A=1) = 0.80, \quad P(R=1 \mid A=0) = 0.10$.

$T$: Surface-to-Air Missile (SAM) Intercept Failure ($1$) vs. Success ($0$).

$P(T=1 \mid R=1) = 0.70, \quad P(T=1 \mid R=0) = 0.05$.

The network structure is a causal chain: $A \to R \to T$.

If electronic intelligence confirms that an adversary jammer is active ($A=1$), compute the probability that the intercept fails ($P(T=1 \mid A=1)$) by marginalizing out the unobserved radar tracking noise ($R$).


<details>
  <summary>Show solution</summary>

**Step 1:** Categorize the variables for the query $P(T=1 \mid A=1)$.

Query variable: $T=1$

Evidence variable: $A=1$

Hidden variable: $R \in \{0, 1\}$

**Step 2:** Formulate the marginalization equation summing over all states of the hidden variable $R$:


$$P(T=1 \mid A=1) = \sum_{r \in \{0, 1\}} P(T=1, R=r \mid A=1)$$

$$P(T=1 \mid A=1) = \sum_{r \in \{0, 1\}} P(R=r \mid A=1) \cdot P(T=1 \mid R=r)$$

**Step 3:** Evaluate each term in the sum:

For $R=1$ (High noise):


$$P(R=1 \mid A=1) \cdot P(T=1 \mid R=1) = 0.80 \times 0.70 = 0.5600$$

For $R=0$ (Low noise):


$$P(R=0 \mid A=1) \cdot P(T=1 \mid R=0) = (1 - 0.80) \times 0.05 = 0.20 \times 0.05 = 0.0100$$

**Step 4:** Sum the joint probabilities:


$$P(T=1 \mid A=1) = 0.5600 + 0.0100 = 0.5700$$

**Answer:**
$0.5700$ (or $57.00\%$). When an adversary jammer is active, the probability of an intercept failure increases to $57\%$.

</details>

**Diagnostic Inference with Normalization**
Using the same air-defense network ($A \to R \to T$) from Exercise 1:

$P(A=1) = 0.20, \quad P(A=0) = 0.80$

$P(R=1 \mid A=1) = 0.80, \quad P(R=1 \mid A=0) = 0.10$

$P(T=1 \mid R=1) = 0.70, \quad P(T=1 \mid R=0) = 0.05$

A combat report indicates that a missile intercept has failed ($T=1$). The state of the radar ($R$) was not logged. Compute the posterior probability that an adversary jammer was active ($P(A=1 \mid T=1)$).


<details>
  <summary>Show solution</summary>

**Step 1:** Categorize the variables for the query $P(A \mid T=1)$.

Query variable: $A \in \{0, 1\}$

Evidence variable: $T=1$

Hidden variable: $R \in \{0, 1\}$

**Step 2:** Formulate the unnormalized probability distribution $\mathbf{P}(A, T=1)$ by summing over hidden variable $R$:


$$P(A=a, T=1) = \sum_{r \in \{0, 1\}} P(A=a) \cdot P(R=r \mid A=a) \cdot P(T=1 \mid R=r)$$

**Step 3:** Compute the unnormalized probability for $A=1$ (Jammer Active):

$r=1$: $P(A=1)P(R=1 \mid A=1)P(T=1 \mid R=1) = 0.20 \times 0.80 \times 0.70 = 0.1120$

$r=0$: $P(A=1)P(R=0 \mid A=1)P(T=1 \mid R=0) = 0.20 \times 0.20 \times 0.05 = 0.0020$

Total unnormalized for $A=1$:


$$P(A=1, T=1) = 0.1120 + 0.0020 = 0.1140$$

**Step 4:** Compute the unnormalized probability for $A=0$ (Jammer Inactive):

$r=1$: $P(A=0)P(R=1 \mid A=0)P(T=1 \mid R=1) = 0.80 \times 0.10 \times 0.70 = 0.0560$

$r=0$: $P(A=0)P(R=0 \mid A=0)P(T=1 \mid R=0) = 0.80 \times 0.90 \times 0.05 = 0.0360$

Total unnormalized for $A=0$:


$$P(A=0, T=1) = 0.0560 + 0.0360 = 0.0920$$

**Step 5:** Normalize the distribution:
Total evidence probability $P(T=1) = 0.1140 + 0.0920 = 0.2060$.


$$\alpha = \frac{1}{0.2060} \approx 4.8544$$

$$P(A=1 \mid T=1) = \frac{0.1140}{0.2060} \approx 0.5534 \text{ (or } 55.34\%)$$

**Answer:**
$0.5534$ (or $55.34\%$). After observing that an intercept failed, the probability that an adversary jammer was responsible rises from a baseline of $20.0\%$ to $55.34\%$.

</details>

**Common Cause Network Inference (Explaining Away)**
Consider an autonomous naval radar system where an adversary Sub-Surface Drone ($D$) and Surface Wave Action ($S$) both influence Sonar Clutter ($C$):


$$D \to C, \quad S \to C$$

$P(D=1) = 0.05$ (Sub-surface drone present)

$P(S=1) = 0.30$ (Severe sea swell)

$D$ and $S$ are marginally independent: $P(D, S) = P(D)P(S)$.

CPT for Sonar Clutter $P(C=1 \mid D, S)$:

$P(C=1 \mid D=1, S=1) = 0.99$

$P(C=1 \mid D=1, S=0) = 0.90$

$P(C=1 \mid D=0, S=1) = 0.50$

$P(C=1 \mid D=0, S=0) = 0.01$

The acoustic array detects intense Sonar Clutter ($C=1$).

(a) Compute the posterior probability of a drone contact given clutter alone: $P(D=1 \mid C=1)$.

(b) Visual observation confirms severe wave swells ($S=1$). Explain qualitatively why $P(D=1 \mid C=1, S=1) < P(D=1 \mid C=1)$.


<details>
  <summary>Show solution</summary>

**Step 1:** Calculate unnormalized values for $D$ given $C=1$ by summing over hidden variable $S$:


$$P(D=d, C=1) = \sum_{s \in \{0, 1\}} P(D=d) \cdot P(S=s) \cdot P(C=1 \mid D=d, S=s)$$

For $D=1$:

$s=1$: $0.05 \times 0.30 \times 0.99 = 0.01485$

$s=0$: $0.05 \times 0.70 \times 0.90 = 0.03150$

Sum $P(D=1, C=1) = 0.01485 + 0.03150 = 0.04635$

For $D=0$:

$s=1$: $0.95 \times 0.30 \times 0.50 = 0.14250$

$s=0$: $0.95 \times 0.70 \times 0.01 = 0.00665$

Sum $P(D=0, C=1) = 0.14250 + 0.00665 = 0.14915$

**Step 2:** Normalize to find $P(D=1 \mid C=1)$:


$$P(C=1) = 0.04635 + 0.14915 = 0.19550$$

$$P(D=1 \mid C=1) = \frac{0.04635}{0.19550} \approx 0.2371 \text{ (or } 23.71\%)$$

**Step 3:** Explain the shift when $S=1$ is observed:
When wave swell is confirmed ($S=1$), the severe sea state provides an alternative operational explanation for the acoustic clutter. This "explains away" the anomalous sonar return, causing the posterior probability of an enemy drone contact to drop.

**Answer:**
(a) $P(D=1 \mid C=1) \approx 0.2371$ (23.71%).

(b) Confirming severe sea swell ($S=1$) provides an independent physical explanation for the observed clutter ($C=1$). By "explaining away" the acoustic anomaly, the tactical probability of a hostile drone drops significantly.
</details>

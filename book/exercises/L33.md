**2. Positional Encoding**
Two identical ISR reports contain the sentences: "Friendly forces engaged the adversary" and "The adversary engaged friendly forces." Since a Transformer processes an entire document simultaneously in parallel, how does it mathematically differentiate the completely opposite tactical meanings of these two sentences?


<details>
  <summary>Show solution</summary>

**Step 1:** Identify the limitation of parallel processing. Throwing all words into the network at once destroys their sequential order.

**Step 2:** Identify the architectural solution used by Transformers before the data enters the attention layers.

**Answer:** The Transformer uses Positional Encoding. It mathematically attaches a unique "time-stamp" (or position ID) to each token before feeding them into the network. This permanently tags the exact sequential order of the subjects and verbs, preserving the tactical context while still allowing blazingly fast parallel processing.

**3. Self-Attention (Queries, Keys, and Values)**
An AI is analyzing a lengthy intelligence report. On page 2, it reads "The 101st Airborne set up a forward operating base." On page 15, it reads "They deployed radar." How does the Self-Attention mechanism use Queries, Keys, and Values to figure out who "They" refers to?


<details>
  <summary>Show solution</summary>

**Step 1:** Define the Query. This is the current token the model is trying to understand. (Query = "They").

**Step 2:** Define the Keys. These are the mathematical labels/identifiers of all other words in the document, describing what information they contain. (Key = "101st Airborne").

**Step 3:** Calculate the attention score via the dot product. The Query ("They") mathematically aligns with the Key ("101st Airborne"), resulting in a massive attention weight.

**Answer:** The token "They" acts as the Query, searching the document. The phrase "101st Airborne" acts as a highly relevant Key. Because their dot product yields a high attention score, the network pulls the semantic Value of the 101st Airborne into its contextual understanding of the word "They".

**4. Training Paradigms: Base vs. Instruct**
You are testing a locally hosted LLM on a secure network. You type the prompt: "Extract the target coordinates from this transcript:" Instead of providing the coordinates, the model outputs: "Extract the target altitude from this transcript:" What phase of training is this model missing, and why did it produce that output?


<details>
  <summary>Show solution</summary>

**Step 1:** Analyze the model's behavior. Instead of obeying a command, it is simply continuing a perceived pattern (replacing "coordinates" with "altitude").

**Step 2:** Relate this behavior to the Pre-Training phase, where the model only plays a game of "predict the next word" using internet text.

**Answer:** The model is a raw Base Model that has only undergone Pre-Training. It does not know it is supposed to be an assistant; it is merely continuing a text pattern. To fix this, it must undergo Instruct-Tuning, where it is heavily trained on prompt/response pairs to learn how to obey explicit commands.

</details>

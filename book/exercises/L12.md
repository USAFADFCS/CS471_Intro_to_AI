# Markov Decision Processes II

**1. Deterministic vs. Stochastic Policies**
In the context of an autonomous ground vehicle navigating a combat zone, define both a deterministic policy and a stochastic policy.

<details>
  <summary>Show solution</summary>
  
**Step 1:** Define a deterministic policy.
A deterministic policy is a strict rulebook that selects exactly one specific action per state[cite: 7]. For example, if the vehicle detects a roadblock (State), it will *always* reroute to the left (Action).

**Step 2:** Define a stochastic policy.
A stochastic policy assigns mathematical action probabilities to each state[cite: 7]. For example, if the vehicle detects a roadblock, it might assign a 60% probability to rerouting left, and a 40% probability to rerouting right, making its behavior less predictable to an observing adversary.

**Answer:** A deterministic policy selects one action per state; a stochastic policy assigns action probabilities[cite: 7].
</details>

**2. Optimal State-Value Functions**
When analyzing an MDP for a theater air-defense network, what exactly does the optimal state-value function ($V^*(s)$) represent?

<details>
  <summary>Show solution</summary>
  
**Step 1:** Identify the purpose of a state-value function.
A state-value function evaluates how "good" it is for an agent to be in a specific state by estimating the total future rewards it will gather from that point onward.

**Step 2:** Identify the meaning of the "optimal" (*) designation.
The optimal designation means the agent is no longer following a random or flawed policy; it is making the absolute mathematically best decisions possible from that state until the end of the episode.

**Answer:** It represents the maximum expected discounted return achievable from each state[cite: 7].
</details>

**3. Action Value Comparisons**
A tactical satellite must choose between two orbital maneuvers to optimize its intelligence collection:
*   **Action A:** Yields a reward of $+4$ and immediately ends the collection window.
*   **Action B:** Yields a reward of $+1$ now, and a reward of $+4$ on the next step.
Given a high-volatility environment where the discount factor $\gamma = 0.5$, mathematically compare the returns and identify the preferred action for the satellite's automated policy.

<details>
  <summary>Show solution</summary>
  
**Step 1:** Calculate the expected return for Action A.
Because Action A terminates the sequence immediately, the return is simply the immediate reward: $G_A = 4$[cite: 7].

**Step 2:** Calculate the expected discounted return for Action B.
Apply the discount factor equation: $G_B = R_0 + \gamma R_1$. 
$G_B = 1 + 0.5(4)$[cite: 7].
$G_B = 1 + 2 = 3$[cite: 7].

**Answer:** A = 4; B = 1 + 0.5(4) = 3; choose A[cite: 7]. Action A is preferred because its expected discounted return ($4$) is strictly greater than Action B's return ($3$).
</details>

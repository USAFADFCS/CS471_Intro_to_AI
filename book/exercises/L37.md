**1. ReAct Loop Components**

In the ReAct architecture, which step is responsible for injecting the external data (e.g., a database query result) back into the agent's context window: the Thought, the Action, or the Observation?

<details>
  <summary>Show solution</summary>

**Step 1:** Define the three steps of the ReAct loop.

**Thought:** The agent's internal reasoning.

**Action:** The agent executing a tool call.

**Observation:** The result returned by the external tool.

**Step 2:** Match the function to the definition. The external data is the result of the tool call.

**Answer:** The **Observation** step is responsible for injecting the external tool results back into the agent's context window.

</details>

**2. Agentic Memory**

An AI agent successfully plans a complex convoy route avoiding hostile terrain. The developers want the agent to recall this specific successful route layout if asked to plan a similar mission three months later in a completely new chat session. Which capability must be implemented to achieve this: Short-Term Memory (Context Window), Long-Term Memory (RAG/Vector Store), or the Adjudicator Agent?

<details>
  <summary>Show solution</summary>

**Step 1:** Analyze the time horizon. The requirement is for the agent to remember information across different chat sessions, months apart.

**Step 2:** Evaluate the memory types. Short-term memory (the context window) is cleared every time a new session starts. Therefore, persistent storage is required.

**Answer:** The developers must implement Long-Term Memory (RAG/Vector Store) to allow the agent to retrieve past operational successes across isolated sessions.

</details>

**3. Multi-Agent Wargaming Risks**

During a simulated multi-agent wargame, the Red Team agent outputs: "I will deploy our stealth hover-tanks." The Adjudicator agent accepts this move, and the Blue Team begins allocating resources to counter hover-tanks. What specific failure mode has occurred in this multi-agent system?

<details>
  <summary>Show solution</summary>

**Step 1:** Analyze the Red Team's output. "Stealth hover-tanks" do not exist in standard military capability, meaning the LLM has invented a false fact.

**Step 2:** Identify how this failure propagates in a multi-agent setup. Because the Adjudicator failed to reject the false fact, the Blue Team treats the hallucination as reality, derailing the simulation.

**Answer:** This is a prime example of a Cascading Hallucination. One agent hallucinates a capability, and because the system fails to correct it, subsequent agents accept the hallucination as truth, rendering the wargame invalid.

</details>

**1. AI Components** 

An autonomous supply drone uses a camera to look for a designated drop zone marked by a green smoke grenade. It filters the video feed to isolate the color green, compares the green blob's shape to a database of known smoke plumes, and then sends a command to the servos to release the cargo.

Map this scenario to the four major components of the AI pipeline.


<details>
  <summary>Show solution</summary>


**Step 1:** Identify Data Ingestion. The raw input is the drone's camera video feed.

**Step 2:** Identify {term}Preprocessing / {term}Feature Extraction. The system filters the video to isolate the color green and extracts the shape of the blob.

**Step 3:** Identify Modeling / {term}Inference. The system compares the extracted shape against a database to confirm it is a smoke plume.

**Step 4:** Identify Output. The system translates the positive identification into a physical actuator command to release the cargo.

**Answer:**

* Ingestion: Camera feed.

* Preprocessing: Color filtering & shape extraction.

* Inference: Database comparison.

* Output: Servo release command.

</details>

**2. AI Techniques**

You are developing a system to manage a swarm of reconnaissance micro-drones. Which AI technique (Search, Learning, or Inference) should you use for the following sub-tasks?
A) Determining the optimal flight path through a dense urban canyon.
B) Identifying whether a detected radio signal belongs to an enemy squad or civilian infrastructure based on past examples.

<details>
  <summary>Show solution</summary>


**Step 1:** Analyze Task A. Finding an optimal path through a known or partially known physical space is a classic pathfinding problem. This requires a Search algorithm.

**Step 2:** Analyze Task B. Categorizing a signal based on historical examples requires the system to recognize patterns from past data. This requires a Learning algorithm.

**Answer:**
Task A utilizes Search, while Task B utilizes Learning.
</details>

**3. Mathmatical Transformations**

A temperature sensor on a server rack provides raw inputs in Fahrenheit ($x$). The *Preprocessing* module must normalize this by converting it to Celsius ($y$) before passing it to the inference engine.

Calculate the exact preprocessed output $y$ if the raw sensor input is $x = 113$ using the transformation function $y = (x - 32) \times \frac{5}{9}$.


<details>
  <summary>Show solution</summary>

**Step 1:** Substitute the input value into the transformation function: $y = (113 - 32) \times \frac{5}{9}$

**Step 2:** Perform the subtraction inside the parentheses: $113 - 32 = 81$

**Step 3:** Multiply by the fraction: $y = 81 \times \frac{5}{9} = 9 \times 5 = 45$

**Answer:** The preprocessed output passed to the inference engine is 45°C.
</details>

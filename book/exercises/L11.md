### Read the following scenarios. For each scenario, you must:
* (a) Define a reasonable state representation.
* (b) Identify one action, one possible transition outcome, and one reasonable reward.
* (c) Explain whether a reduced, specific state representation satisfies the Markov property.

**1. Cyber-Defense AI**
A cyber-defense agent chooses whether to block, monitor, or ignore a network connection. Current evidence and system load affect what happens next.

<details>
  <summary>Show solution</summary>
  
**Part (a):** 
A reasonable state representation must capture all the environmental variables that influence the outcome of the agent's actions. 
State $S = (\text{System\_Load}, \text{Threat\_Confidence\_Level}, \text{Connection\_Status})$.

**Part (b):** 
*   **Action:** Block Connection.
*   **Transition:** If the agent chooses "Block" while in the state (Load=High, Threat=High, Status=Active), there is a 95% probability the next state will be (Load=Normal, Threat=Low, Status=Closed) and a 5% probability the connection evades the block and remains Active. 
*   **Reward:** +50 for successfully closing a High-Threat connection, -10 for blocking a benign connection (interrupting friendly traffic).

**Part (c):** 
A state containing *only* the source IP address does **not** satisfy the Markov property. The Markov property dictates that the outcomes of future actions must depend *only* on the current state, completely independent of the past[cite: 8]. An IP address alone does not capture the current system load or the recent behavioral history (threat confidence) required to predict what will happen if the agent chooses to "Monitor" or "Block"[cite: 8].

**2. Autonomous Medevac UAV**
An autonomous medevac UAV must navigate through a contested canyon to extract a casualty. It can choose to fly high, fly low, or hover. Fuel levels and enemy radar activity fluctuate based on altitude.

<details>
  <summary>Show solution</summary>

**Part (a):** 
A reasonable state representation needs to capture the UAV's physical location, its resources, and the threat environment. 
State $S = (\text{Grid\_Position}, \text{Fuel\_Level}, \text{Radar\_Lock\_Status})$.

**Part (b):** 
*   **Action:** Fly Low.
*   **Transition:** If the agent chooses "Fly Low" while Radar_Lock=True, there is an 80% probability the next state transitions to Radar_Lock=False (successfully masking the UAV in terrain), but a 10% probability of transitioning to a "Crashed" terminal state. 
*   **Reward:** +500 for reaching the extraction grid, -1000 for crashing, and a living reward of -1 per step to penalize fuel consumption.

**Part (c):** 
A state containing *only* the $(x, y)$ grid position does **not** satisfy the Markov property. If Fuel_Level is excluded from the current state, the probability of the UAV transitioning to a "Crashed" state due to fuel exhaustion depends on the *history* of how long the UAV has been flying. Because the future outcome relies on historical steps rather than just the current state, the Markov assumption is violated[cite: 8].
</details>

**3. Naval Anti-Submarine Warfare (ASW) Asset Allocation**
A naval commander allocates sensor resources to track an enemy submarine. The agent can choose to use Active Sonar, Passive Sonar, or run Silent. The sea state (calm/rough) and the commander's contact confidence change dynamically over time.

<details>
  <summary>Show solution</summary>

**Part (a):** 
A reasonable state representation must include the environmental conditions affecting the sensors and the current tracking status. 
State $S = (\text{Sea\_State}, \text{Contact\_Confidence\_Level}, \text{Own\_Ship\_Detectability})$.

**Part (b):** 
*   **Action:** Active Sonar.
*   **Transition:** If the agent chooses "Active Sonar" during Sea_State=Calm, there is a 90% probability the Contact_Confidence_Level transitions to "High", but a 60% probability that Own_Ship_Detectability transitions to "Exposed".
*   **Reward:** +100 for achieving High contact confidence, -200 if Own_Ship_Detectability becomes Exposed (counter-detected by the enemy).

**Part (c):** 
A state containing *only* the Contact Confidence Level violates the Markov property. The transition probabilities for sonar success heavily depend on the unobserved Sea_State. Without the Sea_State included in the current state, the model would have to look backward at past weather reports (historical states) to accurately predict the outcome of using sonar, breaking the rule that the future is independent of the past given the present[cite: 8].
</details>
